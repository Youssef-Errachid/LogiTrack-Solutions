# LogiTrack Solutions
A full-stack logistics management application built with Spring Boot and React.

## Technologies
-Backend: Spring Boot 
-Frontend: React + Vite
-Database: MySQL 
-Build Tool: Maven

## Project Structure
Logitrack/
|--backend/    #Spring Boot REST API
|--frontend/   #React + Vite 
 --README.md 

 ## Getting Started 

 ## Backend 
---- using commands 
cd backend 
./mvnw spring-boot:run 


##Frontend 
---- using commands 
cd frontend
npm install 
npm run dev
